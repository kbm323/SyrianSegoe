SyrianSegoe Korean · {{VERSION}} · Windows 11 x64
============================================================

처음 시작하기
------------
1. ZIP을 폴더에 모두 풀고 SyrianSegoe-Korean.exe를 실행합니다.
   GUI 실행에는 Python이나 FontForge 설치가 필요하지 않습니다.
2. 공식 Pretendard 1.3.9 일반판 ZIP을 별도로 받습니다.
   https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
3. 앱 위쪽 「한국어 Windows 11 · Pretendard」에서
   public/variable/PretendardVariable.ttf를 선택합니다.
   JP / Static / OTF는 GUI 설치용 입력으로 사용하지 않습니다.
4. 「빌드·검증」을 누르고 저장 폴더를 고릅니다.
   완료 안내까지 기다리세요. 빌드만으로 시스템은 변경되지 않습니다.
5. 적용을 결정하면 「검증된 글꼴 적용」을 누릅니다.
   관리자 창이 다시 열리면 적용 버튼을 다시 누릅니다.
6. 작업을 저장하고 직접 재부팅합니다.

원본으로 복원하기
-----------------
「원본 복원 / Restore」 → 관리자 창에서 다시 복원 → 재부팅.
잠긴 파일 오류가 있으면 재부팅한 뒤 복원을 다시 실행합니다.
백업·변경 기록·Restore.reg:
%USERPROFILE%\Documents\SyrianSegoe\Original_Segoe_Backups

다운로드 확인
-------------
SHA256SUMS.txt는 EXE와 문서의 SHA-256 해시를 담고 있습니다.
PowerShell에서 Get-FileHash .\SyrianSegoe-Korean.exe -Algorithm SHA256
결과를 SHA256SUMS.txt의 같은 파일 항목과 비교합니다.
VERSION.json에는 배포 버전, 소스 커밋, EXE 해시가 있습니다.
uploaded-preview / unverified는 업로드 파일의 참고용 패키지이며
공식 버전이나 소스 출처를 검증했다는 뜻이 아닙니다.

알려진 제한
-----------
Windows 전체 UI와 재부팅 후 실제 적용·복원은 아직 미검증입니다.
진행 막대는 빌드 중 계속 증가하지 않을 수 있습니다.
일부 UI는 원래 글꼴을 사용하며 Variable의 opsz 디자인에는 제한이 있습니다.
EXE는 서명되지 않았습니다. 앱 제어가 차단하면 정책을 해제하지 말고
README.ko.md의 Python 소스 실행 방법을 참고하세요.
Windows 원본·Pretendard·생성 TTF는 이 ZIP에 포함하지 않습니다.
