## Windows 11 + Pretendard, GUI로 시작하기

SyrianTurk/SyrianSegoe의 기존 GUI와 빌드·설치·복원 코드를 재사용한 한국어 사전 릴리즈입니다.

### 다운로드

| 파일 | 용도 |
| --- | --- |
| **[SyrianSegoe-Korean.exe](https://github.com/kbm323/SyrianSegoe/releases/download/v0.5.0-ko.1/SyrianSegoe-Korean.exe)** | 바로 실행하는 GUI. 일반 사용자에게 권장 |
| [SyrianSegoe-Korean-Windows-x64.zip](https://github.com/kbm323/SyrianSegoe/releases/download/v0.5.0-ko.1/SyrianSegoe-Korean-Windows-x64.zip) | GUI + 빌드/설치 CLI + 한국어 안내 + 라이선스 |
| [SHA256SUMS.txt](https://github.com/kbm323/SyrianSegoe/releases/download/v0.5.0-ko.1/SHA256SUMS.txt) | EXE/ZIP 다운로드 무결성 확인용 해시 |

Windows 11 x64용입니다. GUI 사용에는 Python·FontForge·GitHub 로그인이 필요하지 않습니다. 아래 자동 생성되는 Source code ZIP은 실행 파일이 아닌 소스입니다.

### 사용 순서

1. GUI 실행 → 홈 위쪽 **한국어 Windows 11 · Pretendard**.
2. [공식 Pretendard 1.3.9](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9)의 일반판 ZIP을 풀고 `public/variable/PretendardVariable.ttf` 선택.
3. **빌드·검증** → 저장 폴더 선택 → 완료 안내까지 기다리기. 빌드만으로 시스템은 변경되지 않습니다.
4. **검증된 글꼴 적용** → 관리자 권한으로 다시 열린 뒤 버튼을 다시 누르기 → 작업 저장 후 직접 재부팅.
5. 필요하면 **원본 복원 / Restore** → 관리자 창에서 다시 복원 → 재부팅.

### 포함된 변경

- 한글 5개 범위의 cleanup/subset 보호 및 현대 한글 11,172자 검사.
- Segoe UI 6종·맑은 고딕 3종·실제 weight 가변 Segoe UI Variable 1종 빌드.
- 원본 이름·줄높이·스타일과 Variable 축/명명된 인스턴스 유지.
- 적용 전 해시·글리프·metadata·외곽선 재검증, 영구 백업 및 journal/Restore.reg.
- Fluent Icons·MDL2·Emoji·Symbol 제외. 보호된 Windows 원본 파일은 덮어쓰지 않음.

### 검증과 알려진 제한

39개 테스트, GUI 이벤트 루프, 임시 Fonts 폴더/가상 레지스트리에서 적용·복원, Windows CI 패키징을 검증했습니다. 공식 Pretendard로 실제 10종 생성과 Windows 프로세스 내부 글꼴 로드도 확인했습니다. **실제 시스템 전체 UI·재부팅 후 적용 및 복원은 아직 미검증**이므로 사전 릴리즈로 제공합니다.

빌드는 수 분 이상 걸릴 수 있습니다. 현재 진행 막대는 시작과 완료 때만 바뀌고 처리 중 창 닫기를 막습니다. 한자는 맑은 고딕으로 보완하며 Variable opsz와 굵기별 조판에는 제한이 있습니다. 일부 Windows UI는 원본 경로를 직접 읽어 변경되지 않을 수 있습니다.

EXE는 서명되지 않았습니다. Windows 앱 제어가 차단하면 정책을 해제하지 말고 소스 실행 방법을 사용하세요. 실행 파일과 소스는 제공하지만 Windows 원본·Pretendard·생성 TTF는 포함하지 않습니다.
